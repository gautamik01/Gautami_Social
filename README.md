# Gautami Kasat: interactive portals

Interactive studies of cities, built from coursework and personal projects.
Live site: https://gautamik01.github.io/Gautami_Social/

## The layout

```
index.html     the landing page (one card per project)
projects/      one numbered folder per project; each folder is one live page
templates/     master designs to start new projects from
```

Inside every project folder:

| File | What it is | Edit it? |
|---|---|---|
| `index.html` | The page: title, text, settings | Yes. Look for `EDIT ME` |
| `style.css` | How it looks | Only for look tweaks |
| `map.js` | How it behaves | Leave to Claude |
| `data.js` | The numbers the map reads | Leave to Claude |
| `notebook.ipynb` | The analysis behind it | |
| `linkedin.md` | The LinkedIn caption | Yes |

## Editing a page

- On the web: open `github.com/gautamik01/Gautami_Social`, go to the project folder, click `index.html`, then the pencil icon. Commit, and the live page updates in about a minute.
- On your laptop: GitHub Desktop, Fetch origin, Pull, Open in Visual Studio Code, edit, save, double-click `index.html` to preview, then Commit and Push.

Big original data stays on the computer only, outside this repo.
Built with AI assistance (Claude) after each assignment was submitted and graded.
